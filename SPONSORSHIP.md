Current flagship work includes:

- **Codex Unchained** — alternative inference backends for Codex CLI workflows

## What sponsorship helps cover

Financial or infrastructure support is used for work such as:

- hosting and cloud services
- model/API usage
- test hardware and devices
- CI/CD and release infrastructure
- security maintenance
- platform compatibility testing
- documentation and onboarding
- time spent maintaining free public releases

## Ways companies can help

Useful support can include:

- direct project sponsorship
- cloud/infrastructure credits
- hardware for compatibility testing
- API/model credits
- funding a clearly defined maintenance milestone
- long-term corporate open-source support

Sponsorship does **not** buy undisclosed control over the roadmap or automatic priority over security and project quality.
